# 📖 Data Dictionary

This document describes all variables used in the biochar–okra experiment.

| Variable | Description | Unit |
|----------|-------------|------|
| Treatment | Biochar treatment code | 5 |
| Replication | Replication number | 3 |
| Plant_Height | Plant height | cm |
| SPAD | Chlorophyll content | SPAD |
| Pods | Number of pods | Count |
| Shoot_FW | Shoot fresh weight | g |
| Nitrogen | Total nitrogen concentration | % |
| Phosphorus | Available phosphorus | mg kg⁻¹ |
| Potassium | Extractable potassium | mg kg⁻¹ |
